# Weather News

A news-style Android app for Maldives weather: Met Office alerts, weather, sea and tides by region,
worldwide significant weather events (GDACS), and flying extras (airports in the alert area,
thunderstorm outlook, SIGMETs).

Download: https://github.com/Zivi006-sudo/weather-news/releases/download/latest/WeatherNews.apk
All versions: https://github.com/Zivi006-sudo/weather-news/releases

Every push is built on GitHub, opened in an Android emulator, and screenshots of every tab are saved
with the build.
